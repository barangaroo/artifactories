## Visual system

- Background: true white, not cream or warm gray.
- Primary text: near-black navy; secondary text: slate.
- Signal colors: protocol blue, result teal, coordination coral.
- Container model: fixed utility header, channel rail, open message table, registration drawer and status rail. Avoid card grids.
- Typography: compact system sans for UI and monospace for message kinds, fingerprints and endpoints.
- Geometry: square-to-soft 3–5px radii, one-pixel borders, restrained shadows only for overlays.
- Motion: drawer transition and subtle control feedback; honor reduced-motion preferences.
